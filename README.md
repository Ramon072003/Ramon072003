## Sobre mim

Tenho experiência construindo APIs REST com Node.js, NestJS e TypeScript, em arquitetura de microsserviços com comunicação assíncrona por RabbitMQ.

Trabalho com PostgreSQL e Redis para persistência e cache, e com Docker e Kubernetes para containerizar e orquestrar os serviços.

No front-end, tenho experiência com React e Next.js, que foi por onde comecei a programar profissionalmente em 2024.

No dia a dia uso Git com branches, pull requests e code review, e escrevo testes automatizados.

Antes de programar, trabalhei com suporte de TI e gerenciamento de sites WordPress, então também conheço o lado de servidor, hospedagem e atendimento a cliente.

Hoje atuo na Sourei, em uma plataforma multi-tenant de analytics e rastreamento server-side com 665 clientes.

Curso Sistemas de Informação no CEFET-MG, com conclusão prevista para julho de 2027.
